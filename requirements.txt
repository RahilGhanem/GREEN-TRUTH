# GreenTruth deployment dependencies
#
# The app runs with the Python standard library only and the rule-based fallback
# detector. This is the Vercel-safe default: it keeps the serverless bundle small
# enough to deploy while still serving the full app and API.
#
# Optional local-only model support (not installed for Vercel):
#   python -m venv .venv
#   .venv/Scripts/python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
#   .venv/Scripts/python -m pip install "transformers>=4.45"
#
# Without torch/transformers, GreenTruth runs in transparent rule-based mode and
# reports that fallback on the UI and /api/health.
#
# The model packages are intentionally omitted here because Vercel bundles every
# Python dependency into a single serverless function and the full torch +
# transformers stack exceeds the Lambda/package limit.
#
# For local experiments with the ClimateBERT detector, install the optional
# packages above instead of relying on the deployment bundle.
