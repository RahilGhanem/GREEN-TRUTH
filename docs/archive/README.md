# docs/archive/

Historical working documents, kept for transparency about how the project evolved. They
are **not maintained** and are superseded by the current documentation:

| File | What it was | Superseded by |
|---|---|---|
| `AUDIT_AND_UPGRADE_PLAN.md` | early technical audit, landscape notes and upgrade plan, written before the real data was in place | README.md, docs/ARCHITECTURE.md, docs/RESEARCH_METHOD.md |
| `IMPLEMENTATION_STATUS.md` | a dated audit log of defects found and fixed during development | docs/LIMITATIONS.md, RESULTS.md |

Statements in these files describe the project at the time they were written (for example
"methane has never run", "the detector has not been measured", "5 of 6 tests pass"). None of
those statements is current, and their external references were not re-verified for the
final build. Do not quote them as current results.
